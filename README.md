# 컷룸

대본 구간을 기준으로 영상, 이미지, 자막과 음성을 편집하는 Tauri 앱입니다.

## Windows 설치

[최신 릴리스](https://github.com/skadnr3126/CUTROOM/releases/latest)에서 Windows 설치 파일을 받아 실행하세요. 설치 프로그램이 컷룸, MCP 서버와 실행에 필요한 Node.js를 함께 설치하고 현재 사용자의 Codex에 `cutroom`을 등록합니다. 컷룸에서 프로젝트를 연 뒤 새 Codex 대화에서 **컷룸 타임라인 조회해줘**라고 요청해 연결을 확인하세요.

## Codex 작업 폴더 준비

새 작업 폴더의 맨 위에 [영상 편집용 AGENTS.md](integrations/codex-workspace/AGENTS.md)를 넣고 그 폴더를 Codex에서 엽니다. 기존 작업 지침이 있으면 내려받은 파일의 컷룸 부분만 추가하세요. 같은 파일이 Windows 설치 폴더의 `mcp/AGENTS.md`와 GitHub 릴리스에도 포함됩니다. 컷룸을 업데이트하면 새 Codex 대화에서 `workspace_guide`를 통해 해당 설치판의 편집 절차를 읽습니다. 작업 폴더와 편집 프로젝트는 서로 다른 위치에 둘 수 있습니다.

## 프로젝트

컷룸을 켜면 홈에 최근 프로젝트의 이름과 폴더 경로가 표시됩니다. **이어서 편집**으로 마지막 작업을 열거나 목록에서 다른 프로젝트를 선택하세요. 옮겨 온 작업은 **기존 프로젝트 열기**에서 해당 폴더의 `project.json`을 선택하면 열립니다. **기존 폴더 열기**로 폴더를 직접 선택할 수도 있습니다. **새 프로젝트**에서 이름과 저장 위치를 정하면 전용 폴더가 생깁니다. 편집기 왼쪽 위 **컷룸 로고**를 누르면 같은 창에서 홈으로 돌아옵니다.

다른 컴퓨터로 옮길 때는 홈에서 프로젝트 옆 **패키지 내보내기**를 눌러 `.cutroom.zip` 파일을 저장하세요. 대상 컴퓨터의 홈에서 **패키지 가져오기**를 누르고 파일과 저장 위치를 선택하면 로컬 폴더에서 편집을 이어갑니다. 패키지에는 타임라인, 자막, 대본 초안과 미디어가 함께 들어갑니다. 같은 프로젝트가 있으면 편집 시각을 비교해 **별도 복사본**이나 **백업 후 교체**를 선택하세요. 교체하면 이전 버전은 표시된 기존 폴더에 보관됩니다.

홈의 **목록에서 제거**는 최근 프로젝트 목록에서 해당 항목을 숨깁니다. 프로젝트 폴더와 편집 내용은 보관되며, **기존 프로젝트 열기**로 다시 등록할 수 있습니다.

컷룸 MCP의 `timeline`은 열린 프로젝트의 ID와 구간 목록을 반환합니다. `get_selection`은 현재 선택과 타임라인 재생 위치를, `get_asset`은 소스 ID에 해당하는 파일 경로와 오디오 정보를 조회합니다.

프로젝트의 **media** 폴더가 소스 보관함입니다. 탐색기에서 하위 폴더를 만들거나 영상·이미지·음성을 넣으면 편집기에 같은 구조로 표시됩니다. 편집기를 닫아 둔 동안 추가한 파일은 다음에 열 때 반영됩니다. 컷룸에서 폴더나 소스를 옮기고 이름을 바꾸면 실제 경로에도 반영됩니다. 타임라인은 고유 ID를 사용하므로 같은 디스크에서 파일을 옮겨도 기존 연결을 유지합니다. 누락된 소스를 선택하면 **파일 다시 연결**로 대체 파일을 가져올 수 있습니다. **카드 삭제**한 파일은 타임라인 연결을 위해 프로젝트의 `.cutroom-retained`에 보관됩니다.

## 스타일 자막 파일 편집

상세 보기의 자막 블록을 클릭하고 **Delete**를 누르거나, 블록을 우클릭하고 **자막 삭제**를 선택하세요. 같은 시간에 표시되는 여러 줄의 ASS 자막은 한 블록으로 삭제됩니다. **되돌리기** 또는 **Ctrl+Z**로 복구할 수 있습니다.

재생 헤드를 원하는 위치에 놓고 타임라인 상단의 **＋ 자막 추가**를 누르세요. 단축키는 **Ctrl+Alt+C**입니다. 문구를 입력하고 **추가**를 누르면 해당 위치부터 표시됩니다. ASS 구간에서는 주변 자막의 스타일을 이어받습니다. 상세 보기에서 자막을 선택하고 **F2**를 누르면 문구와 시간을 다시 편집할 수 있습니다.

타임라인에서 구간을 선택하고 **ASS 불러오기**로 UTF-8 `.ass` 파일을 엽니다. **ASS 자막 편집**에서 문구와 시작·끝 시간을 고친 뒤 **프로젝트에 저장**을 누르면 미리보기와 MP4 내보내기에 반영됩니다. **ASS 파일로 저장**으로 편집한 자막을 별도 파일로 보관할 수 있습니다. 처음 불러온 파일과 프로젝트에 보관된 자막은 독립적입니다.

## 실행

Node.js와 Windows용 Tauri 빌드 도구가 필요합니다.

```powershell
npm.cmd install
npm.cmd run tauri dev
```

Windows x64 설치판에는 썸네일·자막·녹화·MP4 출력용 `ffmpeg.exe`와 재생 시간·오디오 확인용 `ffprobe.exe`가 포함됩니다. Windows에서 `npm.cmd run tauri dev`를 실행하면 개발용 번들, `%LOCALAPPDATA%\com.namuk.tauri-app\tools`, PATH에서 두 도구를 확인합니다. 빠진 도구가 있으면 설치판과 같은 배포본을 내려받아 SHA-256을 검증한 뒤 개발용 번들에 준비합니다. 프로젝트를 열 때 보관함 영상·오디오의 누락된 재생 시간을 확인해 저장합니다. [Gyan FFmpeg Essentials](https://github.com/GyanD/codexffmpeg/releases/tag/9.0.2)

## 편집

1. 대본 패널의 **직접 쓰기**에서 초안을 작성하세요. TXT·Markdown 속 텍스트는 **파일 텍스트 가져오기**로 초안 끝에 추가할 수 있습니다. 범위를 선택하고 **선택한 구간 추가**를 누르면 타임라인에 한 구간이 생기고 대본에 색으로 표시됩니다. 타임라인에서 구간을 누르면 **직접 쓰기**에서는 연결된 대본 위치로, **편집 구간**에서는 해당 카드로 이동합니다. **편집 구간**에서 대본 내용을 수정하고 저장할 수 있습니다. 구간 목록과 대본 내용 사이의 구분선을 위아래로 움직이면 두 영역의 높이가 바뀝니다. 앱을 다시 열면 마지막으로 선택한 탭과 높이가 복원됩니다.
2. 파일을 앱 안으로 끌어 놓거나 소스 보관함의 **가져오기**로 영상·이미지·음성을 추가한 뒤, 파일을 타임라인의 해당 구간으로 드래그하세요. 영상·이미지는 영상 트랙, 음성은 음성 트랙에 놓습니다. 타임라인의 소스를 클릭하고 **Delete**를 누르면 연결만 해제됩니다. **편집 구간**의 카드를 클릭하고 **Delete**를 누르면 구간 삭제 확인창이 열립니다.
3. 타임라인의 **전체 보기**에서는 모든 구간을 이어서 재생합니다. 썸네일을 누르면 해당 시점으로 이동하고, 빈 구간의 **＋ 영상 추가**를 누르면 영상이나 이미지를 고를 수 있습니다. 구간 카드를 다른 카드의 왼쪽이나 오른쪽 가장자리로 끌면 표시선 위치로 이동하고, 대본 편집 구간 목록과 영상 재생 순서도 함께 바뀝니다. 구간 카드를 더블클릭하면 그 구간의 **상세 보기**가 열립니다. 썸네일을 더블클릭하면 누른 시점부터 편집할 수 있습니다. 구간 이름은 제목에서 **F2**를 누르거나 우클릭 메뉴의 **이름 바꾸기**로 수정하세요. 영상·이미지 소스나 기존 클립을 끌면 상세 보기의 **＋ 트랙** 행이 펼쳐집니다. 이 행에 놓아 새 트랙을 만들 수 있습니다. 기존 영상 트랙에도 소스를 끌어 놓아 추가하고, 클립 본체를 드래그하거나 클립을 선택한 뒤 화살표로 순서를 바꾸세요. 이미지는 표시 시간도 조절할 수 있습니다. 영상 손잡이로 길이를 조절하고 시작 손잡이에서 **Home**, 끝 손잡이에서 **End**를 누르면 원본 경계로 돌아갑니다.
4. 타임라인을 재생하고 **MP4 내보내기**로 720p 편집본을 저장하세요.

타임라인의 **− / ＋** 버튼이나 슬라이더로 가로 배율을 조절하세요. 두 보기 모두 클립의 가로 길이가 재생 시간에 비례합니다. **화면에 맞춤**을 누르면 전체 보기에서는 편집본 전체가, 상세 보기에서는 선택한 구간이 한 화면에 들어옵니다. 맞춤 상태는 창 크기가 바뀌어도 유지되며, 각 보기는 편집 중에 마지막으로 선택한 배율을 기억합니다.

**상세 보기**에서 시간 눈금이나 미리보기의 재생바를 원하는 영상 위치로 옮기고 **클립 나누기**를 누르세요. 양쪽 조각의 길이가 각각 0.1초 이상이면 나눌 수 있습니다. 각 조각은 개별로 드래그해 옮기거나 선택 후 **Delete**로 삭제할 수 있습니다.

**Ctrl+Z** 또는 상단의 **되돌리기**로 클립 분할·삭제와 클립·구간 순서 변경 등 최근 타임라인 편집을 한 단계씩 되돌릴 수 있습니다. 되돌린 결과는 프로젝트에 저장됩니다. 편집 기록은 앱을 실행하는 동안 최근 100단계까지 유지됩니다. 대본 입력 중에는 Ctrl+Z가 해당 입력란에 적용됩니다.

**전체 보기**에서 구간 제목·썸네일·빈 칸을 우클릭해 **구간 삭제**를 선택하거나, 구간을 클릭한 뒤 **Delete**를 누르세요. 확인하면 해당 구간과 그 안의 클립 배치가 삭제됩니다. 타임라인 위의 경계선을 드래그하면 높이를 조절할 수 있고, 조절한 높이는 앱을 다시 열어도 유지됩니다.

소스 카드를 우클릭해 **이름 바꾸기**를 선택하거나 **F2**를 누르면 프로젝트에서 표시하는 이름을 바꿀 수 있습니다.

영상 트랙의 썸네일은 클립의 원본 시각 순서대로 표시됩니다. 클립을 우클릭하고 **클립을 소스 보관함에 추가**를 선택하면 트리밍한 범위의 영상과 원본 소리가 별도 MP4 소스로 등록됩니다. **여기까지 잘라내기**도 잘라낸 부분을 보관함에 저장합니다. Windows에서는 두 작업에 지원되는 GPU를 자동으로 사용하며, GPU로 저장할 수 없으면 CPU로 처리합니다. 소스 카드에서는 **Delete** 또는 우클릭 메뉴의 **소스 카드 삭제**를 사용하세요. 카드 삭제 후에도 타임라인에 배치한 영상은 계속 재생할 수 있습니다.

프로젝트와 가져온 소스의 복사본은 이 기기에 저장됩니다. 영상 및 음성 시작 지점을 지나 소스가 먼저 끝나면 영상은 마지막 프레임을 유지하고 음성은 무음으로 이어집니다.
