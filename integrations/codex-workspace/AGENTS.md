# 컷룸 영상 편집 작업

이 폴더에서 컷룸 편집 요청을 받으면 새 대화의 첫 편집 전에 `cutroom` MCP의 `workspace_guide`를 한 번 읽는다. 컷룸을 업데이트해 다시 연결한 경우에도 읽는다. 여기서 받은 안내는 현재 설치판의 편집 절차이며, 이번 요청과 사용자가 정한 프로젝트별 편집 기준을 우선한다.

현재 프로젝트는 `timeline`으로 확인한다. 같은 PC에서 컷룸에 열린 프로젝트의 이름, 구간 ID, `mediaDirectory`를 사용한다. 사용자가 가리킨 화면은 `get_selection`으로 확인한다. 드라이브 문자와 이전 PC의 절대 경로를 작업 기준으로 삼지 않는다.

사용자가 편집할 자막은 영상과 분리해 둔다. 작업이 끝나면 해당 구간을 다시 조회하고, 생성한 파일이 있으면 저장 경로를 알려 준다.

이전 설치판에서 `workspace_guide`가 보이지 않으면 현재 연결에 표시되는 도구로 진행한다. 연결 자체가 없으면 같은 PC의 컷룸에서 대상 프로젝트가 열려 있는지 확인한다.
