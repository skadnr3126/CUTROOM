# 컷룸 편집 지침

## 작업 대상

- `timeline`으로 열린 프로젝트의 제목과 ID, 구간 순서, 보관함 폴더, `mediaDirectory`를 확인한다. “지금 보고 있는 구간”이나 “여기”라고 하면 `get_selection`으로 선택한 구간과 재생 위치를 확인한다.
- `scene`으로 구간의 리비전, 원본 배치와 자막 트랙을 읽는다. 원본 파일이 필요하면 `get_asset`이 돌려준 경로와 사용 가능 여부, 재생시간, 오디오 정보를 확인한다. 같은 이름의 후보가 여럿이고 선택 정보로도 구분하기 어려우면 대상만 물어본다.

## 자막과 편집 스타일

편집본 타임라인에서 **A**는 현재 재생 위치보다 앞선 자막 시작으로, **D**는 다음 자막 시작으로 이동한다. 전체 보기에서는 구간을 넘어 이동하고, 상세 보기에서는 미리보기 범위 안에서 이동한다. 같은 시각에 시작하는 여러 줄은 한 지점으로 취급한다. 재생 버튼 양옆에서도 같은 동작을 실행할 수 있다.

F2 자막 편집창에서 입력을 잠시 멈추면 프로젝트에 자동 저장된다. **다음 자막**은 현재 수정의 저장을 마친 뒤 같은 구간의 다음 시작 시각으로 이동한다. ASS 편집창은 같은 시각에 시작하는 줄을 함께 표시한다. 입력 오류나 저장 실패가 있으면 현재 문구를 유지한다.

F2 편집창에서 **이 줄 삭제**를 누르거나 한 줄의 문구를 모두 비우면 그 줄만 삭제된다. 편집창을 연 상태에서는 **원래 문구 복원**으로 되돌릴 수 있다. 상세 타임라인에서 여러 줄이 묶인 블록을 Delete로 누르면 줄을 고를 수 있는 편집창이 열린다.

F2 편집창에서 기준 줄의 **＋ 줄 추가**를 누르고 문구를 입력한다. ASS에서는 기준 줄과 시간·스타일이 같은 별도 줄이 생긴다. 고정 위치 자막은 주변에서 같은 스타일로 쓰인 둘째 줄 위치를 우선 사용한다. 아래 공간이 부족하면 같은 시각에 표시되는 자막 묶음을 위로 옮겨 새 줄을 기준 줄 아래에 둔다. 기본 하단 정렬 자막도 새 줄이 아래로 이어진다. 다시 F2를 열면 각 줄을 따로 수정하거나 삭제할 수 있다. 일반 자막에서는 같은 문구에 줄바꿈을 추가한다.

- 새 스타일 자막을 요청하면 Codex가 UTF-8 ASS 파일을 직접 작성하고 `import_ass`로 구간에 넣는다. 지정한 기준 영상이나 기존 ASS에서 화면 해상도, 글꼴, 크기, 여백, 정렬과 표시 시간을 맞춘다. 소스 영상은 별도로 유지해 컷룸에서 자막 문구와 길이를 수정할 수 있게 한다.
- `import_ass`는 구간의 자막 트랙 전체를 교체한다. 기존 ASS의 일부만 수정할 때는 그 파일의 스타일·이벤트를 보존하며 요청한 부분을 고친다. 일반 자막 한 블록은 `add_caption`이나 `delete_caption`으로 편집한다. `captions`는 전체 일반 자막 목록을 저장하므로 남겨야 할 자막을 함께 전달한다.
- 카데나 가이드에서는 대본의 뜻과 게임 용어를 살려 맞춤법·띄어쓰기·말투를 교정한다. 자막 기준은 ‘카데나에 대한 생각’의 난이도·리턴값 구간이다. 기본은 원속도·무음이며, 인게임 소리나 배속은 요청한 장면에만 적용한다. “더 길게”는 원속도 장면을 더 보여 주는 것으로 해석한다. 요청한 인게임 소리는 원본 오디오 트랙을 확인하고, 트랙이 없으면 그 사실을 알린다.

## 구간과 미디어

**스페이스바**를 누르면 현재 미리보기를 재생하고, 다시 누르면 그 위치에서 일시 정지한다. 전체·상세 보기에서는 편집본을, 소스 보기에서는 선택한 영상이나 오디오를 재생한다. 자막·대본 입력 중에는 띄어쓰기로 동작한다.

영상 중간을 잘라내면 편집본 미리보기에서 잘라낸 자리의 앞뒤 장면이 이어서 재생되며, 같은 트랙의 오버레이 영상에도 적용된다.

편집본 미리보기에서 같은 트랙의 이미지 클립 두 개가 맞닿아 있으면 다음 이미지를 미리 불러온다. 전환 시점에 새 이미지가 준비 중이면 직전 이미지를 잠시 유지하다가 교체한다. 두 이미지 사이에 빈 구간을 두면 그 시간만큼 해당 트랙이 비어 보인다.

전체 타임라인에서 BGM 클립을 선택하고 Delete를 누르면 해당 클립만 삭제된다. 원곡은 보관함에 남으며 Ctrl+Z로 배치를 복구할 수 있다.

전체 보기의 구간 제목 막대를 클릭하면 누른 위치로 재생 헤드가 이동한다. 더블클릭하면 해당 위치에서 구간 상세 보기를 연다.

상세 보기에서 **이음새 미리보기**를 켜면 타임라인 양옆에 앞 구간의 끝과 뒤 구간의 시작이 최대 2초씩 표시된다. 양옆의 미리보기 영역이나 위쪽 시간 눈금을 클릭하거나 드래그해 위치를 고른 뒤 재생할 수 있다. 가운데 구간을 계속 편집할 수 있다. **앞 이음새** 또는 **뒤 이음새**를 누르면 해당 경계 양쪽을 최대 2초씩 재생하고 멈춘다. 미리보기 상단의 배속 선택기는 편집본과 소스 재생에 적용되며 내보내기는 프로젝트의 속도를 따른다.

- `list_bgm`으로 보관함 음악의 ID·길이와 현재 BGM 클립을 조회한다. `timeline`에서 시작·끝 구간 ID를 가져온다. `set_bgm`에는 projectId, clip을 보낸다. 추가할 때 새 clip.id를 한 번 생성하고 재시도에도 유지한다. 수정할 때는 직전에 읽은 클립을 expected에 그대로 보내고 clip에는 원하는 변경만 적용한 전체 값을 담는다. `delete_bgm`에는 projectId와 삭제할 클립의 expected를 보낸다.
- start/end는 {sceneId, offsetMs}다. offsetMs 0은 그 구간 시작, null은 길이가 바뀌어도 따라가는 구간 끝이다. volume은 0~100, fadeInMs/fadeOutMs는 배치 전체의 페이드 시간이다. sourceRange의 inMs와 outMs로 원곡 중 반복할 부분을 지정한다. 곡 전체를 쓰려면 null로 설정한다. 편집 화면에서는 BGM의 양끝을 드래그해 배치 범위를 바꾸고, 선택한 클립의 **곡 사용 범위** 막대에서 양끝 또는 사용할 부분을 드래그한다.

전체 타임라인의 BGM 줄에 보관함의 오디오를 놓거나 ‘BGM 추가’에서 선택하면 그 위치부터 원곡 한 번 길이만큼 배치된다. 남은 타임라인이 짧으면 그 끝까지만 배치한다. MCP로 새 BGM을 추가할 때도 별도 범위 요청이 없으면 같은 기준으로 끝 구간과 구간 내 밀리초를 계산한다. 음악을 더 이어 붙이려면 같은 소스를 다시 추가하거나 클립 끝을 드래그해 반복 재생할 범위를 늘린다. 클립 몸통을 끌면 길이를 유지한 채 이동한다. 클립을 클릭해 음량과 페이드를 설정한다. 전체 미리보기·구간 미리보기·MP4 내보내기 모두 같은 곡 위치와 페이드를 사용한다.

- Windows 개발판은 `npm.cmd run tauri dev` 시작 시 FFmpeg와 FFprobe를 확인한다. 도구가 빠져 있으면 설치판과 같은 배포본을 내려받아 준비한다. 이미 실행 중인 개발판은 `%LOCALAPPDATA%\com.namuk.tauri-app\tools`에 둔 두 도구도 사용할 수 있다.
- `rename_scene`은 조회한 구간 ID와 현재 리비전으로 이름을 바꾼다. `move_scene`은 기준 구간 ID를 사용해 바로 앞이나 뒤에 놓는다. 변경 후 `timeline`에서 이름과 순서를 확인한다. `expected`가 필요한 명령이 리비전 충돌을 반환하면 다시 읽고 이번 수정만 반영한다. 자막 시간은 구간 시작 기준 밀리초이며 `seek`로 해당 위치를 보여줄 수 있다.
- 새 이미지·영상·오디오는 대상 프로젝트의 `mediaDirectory` 아래 적절한 폴더에 완성 파일로 놓는다. 임시 렌더 파일은 보관함 밖에서 만든다. `register_output`에는 작업 시작 때 확인한 `projectId`, 새 출력마다 고유한 `jobId`, 파일의 절대 경로를 보낸다. 같은 출력의 재시도에는 동일한 `jobId`를 쓴다.
- 기존 로컬 MP4는 `import_video`로 가져온다. 영상 하나로 구성된 구간의 원본을 같은 길이의 영상으로 교체할 때는 `replace_video`를 쓴다. 완성 구간은 `export_scene`으로 새 MP4 경로에 렌더하고 결과를 확인한다.
- 상세 보기에서 **클립 나누기**를 누르면 재생 위치를 기준으로 양쪽 조각이 타임라인에 남는다. 영상의 일부를 덜어낼 때는 **잘라낼 시작점 지정**을 누른 뒤 재생 헤드를 끝점으로 옮긴다. **잘라내고 삭제**는 그 범위만 타임라인에서 제거한다. **잘라내고 보관함에 저장**은 같은 컷을 적용하면서 덜어낸 범위를 MP4로 보관한다. 우클릭 메뉴의 **클립을 소스 보관함에 추가**는 타임라인에 있는 클립을 그대로 두고 사본을 저장한다.
- MCP에서는 `timeline`의 projectId와 `scene`의 revision을 확인한다. clipId는 clips 또는 overlays 항목의 id다. clips가 비어 있고 visual만 있는 구간은 구간 id를 clipId로 쓴다. 시간은 각 클립의 타임라인 시작 기준 밀리초로, trim.offsetMs가 있으면 그 앞쪽 여백도 포함한다.
- `split_clip`에 projectId, sceneId, expected(구간 리비전), clipId, atMs를 보내 영상·이미지를 둘로 나눈다. `cut_clip_range`에는 projectId, sceneId, expected, range({clipId, startMs, endMs})와 disposition을 보낸다. startMs는 포함하고 endMs는 제외하며, 영상 안에서 양쪽에 100ms 이상 남겨야 한다. disposition이 `discard`이면 타임라인에서 덜어내고, `library`이면 덜어낸 영상을 MP4로 저장해 savedAssetId를 돌려준다. 저장할 보관함 폴더는 선택 인수 folderId로 지정한다. 변경 후 `scene`으로 새 클립 ID와 리비전을 조회한다.
- 앱의 **MP4 내보내기**와 `export_scene`은 렌더링한 조각을 목적지 폴더의 임시 파일에서 합친다. 저장이 끝나면 지정한 이름으로 MP4가 나타난다.

## 컴퓨터 간 이동

홈에서 가져오기를 시작하면 압축을 푼 용량과 퍼센트가 표시된다. 압축 해제 후에는 프로젝트 검사와 열기 단계를 표시한다.

홈에서 패키지를 내보낼 때는 원본 데이터 중 ZIP에 담은 용량과 퍼센트를 표시한다. 파일 저장이 끝나면 완료 메시지에서 경로를 확인한다.

컷룸 홈에서 프로젝트 옆 **패키지 내보내기**를 누르면 타임라인·자막·대본·미디어가 `.cutroom.zip`에 담긴다. 다른 컴퓨터에서는 홈의 **패키지 가져오기**로 열고 `timeline`을 다시 조회한다. 같은 프로젝트가 있으면 편집 시각을 확인해 **별도 복사본** 또는 **백업 후 교체**를 선택한다. Codex 작업 폴더는 편집 프로젝트와 별도로 둘 수 있다.
